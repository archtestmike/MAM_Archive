# MAM_Archive
Project demoing work backups to a remote network storage server.

What is the problem it solves? 💡

The problem it solves is allowing video producers to upload and backup their work to the Media Asset Management (MAM) server and syncs/overwrites new media files. 

Tools/tech used 🧰 
1. Slack webhooks
2. Bash shell scripting
3. GlobalProtect VPN
4. JamfPro/Self-Service

What did you learn? 🧠

I learned how to utilized the listed technologies to create a workflow to help esclate issues and troubleshoot efficiency. Leveraging JamfPro's Self-Service app, I uploaded this project to help video producers upload their work to our MAM server and securely backup their files.
